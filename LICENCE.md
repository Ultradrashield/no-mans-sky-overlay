**No Man's Sky Overlay** is a comprehensive overlay tool for No Man's Sky featuring HUD menu widgets, waypoint markers, resource tracker, quick inventory panel, and scanner helpers.

## ✨ Features

### 🎮 Core Overlay
- HUD Menu — toggle in-game panel without leaving play
- Waypoint Markers — pin custom points of interest on screen
- Resource Tracker — monitor gathered materials in real time
- Quick Inventory — compact view of slots and stacks

### 🎨 Visual Tools
- Scanner Overlay — highlight nearby interactables
- Distance Meter — show range to selected target
- Minimal Theme — low-profile HUD widgets
